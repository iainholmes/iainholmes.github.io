# Collection chapter illustrations

The original **Inquiry**, **Field & Folio** and **Scholar** engravings remain unchanged in the chapter title banners. The later canonical-IH composites have been removed from those banners at the owner's direction.

| Asset | Original illustration |
| --- | --- |
| `inquiry.svg` | Drafting divider, concentric arcs, registration ticks and measured baseline. |
| `field-folio.svg` | Open scholarly book whose spine continues into a pine sprig. |
| `scholar.svg` | Abstract pediment, columns, arched opening and bookplate corners. |

The family retains its original 160 × 120 viewBox, inherited forest/ivory ink and copper accents. Desktop artwork is restored to 72 × 54px with an 18px Dunhill Oblique label; at 800px and below, 48 × 36px with a 17px label. The original placement beside the chapter number above the mobile title is unchanged.

These illustrations are decorative and disappear through the existing chapter `data-active` state whenever an application is revealed. They return with the full collection.

The new, distinct [secondary IH. monograms](../monograms/README.md) are separate assets placed within the collection's folios and transitions. They are not appended to these title-banner illustrations.

`../../_review/identity-refinement.png` and `../../_review/chapter-identity-proof.png` document earlier stages. Current proofs are linked from the monogram usage notes; none is an integrated browser screenshot.
