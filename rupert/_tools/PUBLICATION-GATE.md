# Official access gate
Before publishing a trail recommendation, read the official managing source directly. Approve the manager’s host in official_hosts (never a secondary guide). Record its URL, check date, open/closed status and evidence in data/access-checks.json. Check trail-specific and park-wide alerts. Refresh within seven days of publication; automated release checks must run again on the release day. AllTrails is secondary only. Set discrepancy=true when sources disagree; publishing stays blocked until resolved. Never assume lack of a secondary alert proves access. Withdrawal records remain accessible; frozen publication snapshots are retained as history.
